# توسعة بنوك أسئلة Zark

كل واحدة من الألعاب الـ42 تحتوي الآن على أكثر من 150 سؤالًا بعد إزالة التكرار داخل بنكها. عدد الأسئلة الظاهر في الموقع يأتي من البنك الفعلي مع أسئلة الإدارة، وليس رقمًا ثابتًا في الواجهة.

## المحتوى

- بنوك المعرفة: أسئلة عربية من حقائق Wikidata، مع حفظ رابط الكيان المصدر لكل سؤال. البيانات محفوظة مع الكود؛ لا يعتمد تشغيل الجولة على اتصال Wikidata.
- الكلمات: مفردات وترجمة، مرادفات وأضداد، ترتيب حروف وكلمات، وإكمال الكلمات.
- التفكير: مسائل أنماط وأعداد وحسابات منطقية، مع إجابات محسوبة.
- الصور والرموز: الاحتفاظ بالصور الموجودة، وإضافة إيموجي وأعلام وأسئلة تلميحات عن الشركات والسيارات والألعاب.
- العلوم: أسماء العناصر ورموزها وأعدادها الذرية، وأسئلة تشريح وتصنيف مبسطة للحيوانات.

ألعاب ذات صلة قد تشترك في حقائق، مثل العواصم والبلدان. عدم التكرار والأعداد محسوبان داخل كل لعبة، وليس بوصف مجموع البنوك أسئلة فريدة عالميًا.

## المصادر

- [Wikidata، ترخيص البيانات المنظمة CC0](https://www.wikidata.org/wiki/Wikidata:Licensing). الاستعلامات وتاريخ جلب اللقطة في [question-bank-sources.json](question-bank-sources.json)، وروابط الكيانات مع الأسئلة في `expanded-fact-bank.ts`. هذه لقطة بيانات عامة قابلة للتصحيح، وليست ضمانًا أن كل حقيقة خضعت لمراجعة تحريرية مستقلة.
- [IUPAC: الجدول الدوري](https://iupac.org/what-we-do/periodic-table-of-elements/) لمرجع رموز العناصر وترتيبها.
- تم تأليف تمارين الكلمات والمنطق وأوصاف الأشياء داخل المشروع. لم تُنسخ كلمات أغانٍ أو مقاطع من الكتب والأفلام.

## التحقق والتحديث

```sh
npm run verify
node scripts/lfg-platform-db-isolated.mjs scripts/games-engine-db-smoke.ts
```

الاختبارات تتحقق من حد أدنى ثابت قدره 151، والإجابات غير الفارغة، وقبول الإجابة الصحيحة، و151 جولة غير متكررة لكل لعبة حتى عند ثبات مولد الأرقام العشوائية. توحيد هوية السؤال يمنع اختلاف صياغة سؤال العلم أو العاصمة أو الترجمة من احتسابه سؤالًا جديدًا.

تحديث لقطة الحقائق اختياري، ويتطلب مراجعة البيانات الناتجة قبل نشرها:

```sh
node scripts/expand-question-data.mjs
node scripts/fetch-flag-questions.mjs
node scripts/build-expanded-question-bank.mjs
npm run verify
```

يمكن تمرير أسماء الألعاب إلى أداة الجلب لتحديث جزء محدد. لا توجد هجرة قاعدة بيانات مطلوبة لهذا التغيير.
